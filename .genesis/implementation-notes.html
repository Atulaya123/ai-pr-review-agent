2026-07-27 (2) — Went fully live for M2: pushed the repo to github.com/Atulaya123/ai-pr-review-agent, wired real credentials (GitHub App, Tiger Cloud, and — after both OpenAI and Anthropic turned out to have no billing configured — a new local Ollama provider, zero cost), ran the Tiger Cloud migration (vector+timescale extensions, hypertable confirmed), and drove an actual PR (#1) through the live webhook → LangGraph → GitHub-post pipeline twice. First run 422'd; root-caused to a local model hallucinating a line one past a short file's end, fixed with a diff-aware line-clamp before posting. Second run succeeded for real: the bot posted a genuine CHANGES_REQUESTED review with real findings from real local-LLM reasoning. Also fixed a latent bug where the agent's model string was hardcoded to "mock" regardless of provider (would have broken every real API call), and pinned the test suite to LLM_PROVIDER=mock so a developer's live .env can't leak into CI. Two secrets (a DB password, an ngrok authtoken) were incidentally pasted into chat while debugging — noted for rotation, not blocking. mypy clean, 20/20 tests green. Next: real RAG ingestion, and a persistent deployment so the demo doesn't depend on this laptop staying on.

2026-07-27 — Ran the full genesis ritual (G0-G6) against the existing pr-review-agent.html architecture doc, then built M1 end to end: FastAPI ingress with HMAC+idempotency, a real LangGraph 4-specialist fan-out (security/quality/tests/docs) with a mock LLM client, a confidence-weighted HITL aggregator, an ARQ worker, and Postgres persistence. Verified live — not just unit tests — via docker compose, a running uvicorn server, a running arq worker, and curl: a signed webhook enqueues a job, the worker processes it and persists the result, and the API serves it back. Found and fixed three real bugs along the way (event-loop/engine-cache mismatch under pytest-asyncio, an async lazy-load MissingGreenlet on the findings relationship, and a port collision with pre-existing local services) — all documented in the deviation log above. mypy and the 14-test pytest suite are both green.
